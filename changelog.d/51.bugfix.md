dot-ai answers now render as sanitized Markdown instead of plain text, through a new local `ResponseMarkdown.tsx` renderer. Answers deliberately do not go through Grafana's Text-panel sanitizer (`sanitizeTextPanelContent`): that whitelist is written for markdown an editor typed by hand and permits `<iframe>`, `<img>`, and other remote-embedding elements, which is unsafe once the content being rendered is a model answer built from untrusted cluster telemetry. Remote-embedding elements can no longer appear in a rendered answer. This adds `marked` as a runtime dependency and increases the plugin bundle (`dist/module.js`) from roughly 41 KB to roughly 79 KB, a ~93% increase.
