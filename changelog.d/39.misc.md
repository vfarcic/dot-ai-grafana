Dependabot no longer proposes minor bumps for `@grafana/*`, and the four runtime packages move to 11.4.8. They are webpack externals, so the installed version never ships — it only decides what `tsc` accepts, and pinning it at the reference host version is what makes a green typecheck mean "compiles against the Grafana we target". Patch updates still flow through the `grafana` group, which is where the upstream fixes are.
