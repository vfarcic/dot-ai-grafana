The Bundle Stats workflow now reports the size comparison in the job summary instead of a pull request comment. GitHub issues a read-only `GITHUB_TOKEN` to `pull_request` runs whose head is a fork, whatever the workflow declares, so `grafana/plugin-actions/bundle-size` could never post its comment and the `compare` job failed with a 403 on every contributor PR — permanently red, and only green when the diff stayed under the comment threshold. The job summary needs no write scope, so `pull-requests: write` is gone and fork and non-fork PRs now run the identical path. Growth is still reported rather than enforced, as before; it raises a warning annotation past 5%, and a red `compare` now means the bundle could not be built or measured.
