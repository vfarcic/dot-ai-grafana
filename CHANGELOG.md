## [0.1.0] - 2026-09-03

Initial release. Unsigned alpha: loading requires
`GF_PLUGINS_ALLOW_LOADING_UNSIGNED_PLUGINS=devopstoolkit-dotai-app`.

### Features

- Query tool with natural-language cluster questions, packing Grafana
  Loki/Prometheus/Tempo/Alertmanager context into the dot-ai `{intent}`.
- Remediate tool, analysis only — no execution.
- Configuration page for the dot-ai MCP server URL and Bearer token, with a
  Test connection action.
